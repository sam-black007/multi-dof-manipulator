# Modular Multi-DOF Robotic Manipulator

CAD-designed, 3D-printed multi-DOF manipulator with servo-based actuation for precise object handling.

## Highlights

- SolidWorks CAD for every structural link, tuned for FDM printability
- Servo-driven joints with planned cable routing
- Modular wrist interface for swappable end-effectors
- Fully 3D-printable BOM at a tight budget

## Status

Repeatable pick-and-place demonstrated on small objects. Used as a teaching and research platform.
